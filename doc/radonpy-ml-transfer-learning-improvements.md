# RadonPyの転移学習チュートリアルの改善案

対象: `docs/CECAM_tutorial/polymer_transfer_learning_tutorial.ipynb`
(RadonPy本体のGitHubリポジトリに同梱されている、Sim2Real転移学習のチュートリアルノートブック。
このリポジトリ自体には含まれないが、RadonPyで生成した物性データを機械学習に使う際の
参考として、内容を読み解いた上での改善案をまとめたもの)

## ノートブックの概要

- 元ネタ論文: Minami et al., "Scaling Law of Sim2Real Transfer Learning in Expanding
  Computational Materials Databases for Real-World Predictions"
  (npj Computational Materials, 2025 / arXiv:2408.04042)。
  RadonPyでMD計算した約7万件のポリマー物性(sim)を使って、実験データ(real)が
  少ない物性の予測モデルを転移学習で強化できることを、べき乗則のスケーリング則
  $R(n) = D n^{-\alpha} + C$ で定量的に示した論文。
- このノートブックは、本物の実験データの代わりに、同じ計算データセット
  (HuggingFace上の`yhayashi1986/PolyOmics`)を「データが多い物性(density, source)」
  と「データが少ない物性(bulk_modulus, target)」に分割し、同様の現象を疑似的に
  再現する自己完結型の実験になっている。
- パイプライン: RDKitでSMILES→ECFP6フィンガープリント(2048bit)化 → PyTorchのMLP
  (2048→1024→512→256→1)でdensityを事前学習 → 出力層をリセットしてbulk_modulusで
  微調整 → scipyの`curve_fit`でMAEのべき乗則をフィットし、データ量を増やす効果を
  定量化する。

## 現状の限界と、改善案

### 1. 入力表現(ECFPフィンガープリント)の限界 — 影響度: 大

ECFP(Morganフィンガープリント, radius=3)は、各原子を中心に**局所的な範囲**しか
見ない設計になっている。ビット数(2048)をいくら増やしても、この「見る範囲」自体は
変わらないため、以下が原理的に拾えない。

- 分子全体の大きさ・鎖の長さ(重合度)といった、長距離の構造情報
- 鎖同士の絡み合い・分子間相互作用など、力学物性(bulk_modulus等)を強く左右する
  凝集状態の情報

**改善案:**

- グラフニューラルネットワーク(GNN, 例: メッセージパッシング型)に置き換え、
  複数層の伝播でECFPより広い範囲の構造依存性を捉える
- 重合度・分子量など、鎖の長さに関する特徴量をECFPと別に追加する
- 複数種類のフィンガープリント(ECFP + MACCS + 物理化学記述子)を組み合わせる

bulk_modulusのような力学物性がdensityより予測誤差が大きくなりやすいのは、
主にこの入力表現の限界に起因すると考えられる。

### 2. 転移学習の手法自体が単純 — 影響度: 中

現状は「事前学習(density) → 出力層(head)だけリセット → 微調整(bulk_modulus)」
という一段階の単純な方式(`fit_transfer_score`関数)。

**改善案:**

- 微調整の前半はencoderを凍結してheadだけ学習し、後半で段階的に凍結を解除する
  (encoderが学習した知識を急に壊さないようにする)
- densityだけでなく、Cp・Rg等の複数物性を同時に事前学習させ、より汎用的な
  特徴表現をencoderに学ばせる(マルチタスク事前学習)
- 層ごとに異なる学習率を使う(encoder側は小さく、head側は大きく)

### 3. 検証データが存在せず、ハイパーパラメータが決め打ち — 影響度: 中

`train_model`関数は、渡されたデータを分割せず、固定エポック数
(`PRETRAIN_EPOCHS=20`, `FINETUNE_EPOCHS=60`)学習し続けるだけで、過学習を
学習中に検知する仕組みが無い。`HIDDEN_DIMS`・`DROPOUT`・学習率もすべて
コード上の定数として決め打ちされている。

**改善案:**

- 訓練データの一部を検証用に分離し、エポックごとに検証誤差を記録して
  early stopping(検証誤差が悪化し始めたら学習を止める)を導入する
- Optuna等を使い、ハイパーパラメータ(隠れ層のサイズ、dropout率、学習率)を
  検証データに基づいて探索する

### 4. 頑健性・信頼性の評価が弱い — 影響度: 中

`QUICK_RUN=True`時は`REPEATS=5`と少なく、ノートブック自身のコメントにも
「傾向が単調に改善しない場合がある」旨の注意書きがある。また、モデルは
点推定(1つの数値)のみを出力し、予測の確信度は分からない。

**改善案:**

- 複数シードでのアンサンブル学習を行い、予測を平均して結果のブレを減らす
- MC-DropoutやDeep Ensembleで予測の不確実性(信頼区間)も同時に出力し、
  材料スクリーニング用途での実用性を高める
- `target_train`側(データが少ない256件)に対して、同一分子の別表記SMILESを
  複数与えるなどのデータ拡張を検討する

## 優先順位の目安

今回のように、力学物性(bulk_modulus)のようなECFPでは捉えにくい物性を
対象にする場合、**1番(入力表現の強化)が最も効果が大きい**と考えられる。
局所構造しか見えないという根本的な制約に手を付けない限り、他の改善
(転移学習手法の精緻化、ハイパーパラメータ調整、アンサンブル等)を
積み重ねても効果は頭打ちになりやすい。
